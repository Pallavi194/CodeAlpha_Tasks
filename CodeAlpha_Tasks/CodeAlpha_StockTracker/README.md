## Stock Portfolio Tracker

This project is designed to compute the total value of investments using user-provided data along with predefined stock prices.

## Features

* Allows users to enter stock names and their quantities
* Calculates the overall investment value
* Simple and practical to use

## Concepts Used

* Dictionaries
* Input and output operations
* Basic arithmetic calculations

## How to Run

python stock_tracker.py
