## Projects Completed

### Hangman Game

This is an entertaining text-based game where the player attempts to guess a hidden word one letter at a time. The player has only a limited number of chances to find the correct word.

*What I learned:*
I gained practice using strings, lists,loops, and the random module while creating a small game.

### Stock Portfolio Tracker

This project is designed to calculate the total value of stocks based on user input and predefined stock prices.

*What I learned:*
I learned how to work with dictionaries,accept user input, and perform simple calculations. It also helped me understand how basic programs can be applied to finance related tasks.

### Chatbot

This project is a basic rulr based chatbot that communicates with users using predefined replies. It can answer simple inputs such as greetings and common queries.

*What I learned:*
I learned how to use conditional statements(if-elif), loops, and functions to create basic conversational programs.
