## Chatbot

This project is a basic rule-based chatbot developed using Python. It interacts with users by responding to predefined inputs, making it a great starting point for understanding conversational logic.

### Features

* Responds to greetings like "hello", "hi"
* Handles simple user queries
* Provides predefined answers
* Interactive command-line conversation
  
### Concepts Used

if-elif conditional statements
while loops for continuous interaction
Functions for structured code
Basic string handling

### How to Run

* Make sure Python is installed
* Run the following command in your terminal:
   python chatbot.py
  
### Example Interaction
You: hello
Bot: Hi there! How can I help you?

You: how are you
Bot: I'm just a bot, but I'm doing great!
